# 공유용 작업 스냅샷

이 스냅샷은 로컬 미푸시 작업의 공유용 복사본입니다. 원본 작업 파일은 수정하지 않았습니다.

- 학습지 원본 페이지·문제·도형 PNG 8개와 학습지 사진이 포함된 슬라이드 PNG 1개를 제외했습니다.
- 사진을 내장한 HTML/SVG 3개와 실험 보고서 HTML 1개는 해당 사진만 “원본사진은 로컬 보관” 안내 SVG로 대체했습니다. 모델 출력으로 생성한 앱 렌더 화면은 유지했습니다.
- 중복 공유 ZIP은 제외했습니다.
- 기존 검증 JSON, 입력 체크리스트, 캡처 검사 결과와 연구 수치는 원래 로컬 자료와 실행을 기준으로 합니다. 공유본의 안내 이미지를 모델에 넣어 재실험한 결과가 아닙니다.
- 생성 스크립트와 메타데이터에는 로컬 원본 경로가 남아 있을 수 있습니다. 학습지 원본과 API 키는 포함하지 않습니다. 스크립트를 재실행하려면 해당 입력 자료와 환경 설정을 별도로 준비해야 합니다.
- 참조 입력 이미지가 제외되어 일부 실험 기록의 원본 링크는 공유 저장소에서 열리지 않습니다. 보고서의 직접 표시 이미지 세 곳은 안내 이미지로 대체했습니다.

파일별 원본/복사본 SHA-256 및 변경 기록은 작업자의 외부 `push-main-sanitized-manifest.json`에 보존했습니다.
