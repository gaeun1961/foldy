# 작업 기록 - (간단한 작업명)

> 제목 규칙: `작업 기록 - {작업명}`  
> 예시: `작업 기록 - 접기 애니메이션 + 슬라이더`
>
> 파일 이름: `T{TODO번호 두 자리}-{짧은설명}.md` (날짜·시간은 아래 "일시"에 쓴다)  
> 예시: `T03-fold-animation-slider.md`, TODO와 상관없으면 `T00`(여러 개일 수 있어서 짧은 설명으로 구분)
>
> 언제 쓰나
> - **TODO 하나당 하나만** 쓴다. 같은 TODO에 PR이 여러 개면 새로 만들지 말고 이 파일에 이어서 쓴다 (일시에 날짜를 추가)
> - TODO가 아닌 작은 작업(문서 정리, 설정 변경)은 쓰지 않는다. PR 본문으로 대신한다
> - 예외: 결정이 바뀌었거나 기술적인 문제를 해결한 경우는 TODO가 아니어도 `T00` 리포트를 남긴다

- 일시: YYYY-MM-DD HH:MM (TZ)
- 작성자: (사람 이름)
- 에이전트: (예: Codex / Copilot / Gemini 등, 없으면 `없음`)
- 작업 유형: (예: 기능 추가/버그 수정/리팩터)
