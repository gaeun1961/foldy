- 콘솔 오류 없음

## 발견한 문제

### 꼭 고칠 것
1. **도형이 아래 카드에 가려짐**
   - 펼친 전개도는 처음부터 카드 뒤에 거의 다 숨는다. 다 접은 직육면체는 전혀 안 보인다. 화면을 끌거나 휠로 축소해도 카드 뒤에 남는다
   - 원인: `ThreeViewer.tsx`의 `resize()`가 캔버스 전체를 기준으로 카메라를 맞춘다. 화면 높이의 약 60%를 덮는 `.dock`과 왼쪽 패널(약 316px)은 계산에 넣지 않는다. 지금은 `solidFit` 반지름을 1.6배로 늘리고 target을 z로 조금 옮기는 보정만 있다
2. **부피 화면도 일부 가려짐**: 설명 모드는 `solidFit`으로 다시 맞춰 그나마 보인다. 그래도 다 쌓인 직육면체 아래층과 바닥이 카드에 가린다
3. **차례 버튼이 경고 없이 도형을 지움**: 접기 카드의 "📖 차례"를 누르면 만들던 도형이 확인 없이 사라지고 빈 책으로 돌아간다. 책 속 차례의 "직육면체"를 누르면 다시 만들어지는 것은 정상이다

### 고치면 좋을 것
- **부피 버튼이 혼자 한 줄**: 접기 버튼 줄과 선 긋기 줄 사이에 "부피" 버튼만 한 줄을 차지해 카드가 더 높아진다. 병합하면서 생긴 배치로 보인다 (`LessonControls`가 `FoldControls` 아래에 따로 들어감)
- **보기 메뉴가 안 닫힘**: `<details>`로 열린 보기 메뉴가 바깥을 누르거나 Esc를 눌러도 닫히지 않는다. 보기 버튼을 다시 눌러야만 닫힌다
- **왼쪽 패널 제목 겹침**: 패널을 스크롤하면 "foldy 도형 만들기" 제목 줄이 아래의 "학습지 사진 올리기" 버튼 위에 반투명하게 겹친다
- **빈 책 글씨가 너무 작음**: 첫 화면의 책이 화면 가운데에 작게 나와, 차례와 안내 글을 거의 읽을 수 없다
- **챗봇 창이 그림책과 안 어울림**: 흰색 일반 앱 스타일이다. 열면 접기 카드 오른쪽과 단계 점(`.step-dots`)을 덮는다

## 개선안
1. **아래 카드를 얇은 막대 하나로 줄인다** (근본 해결)
   - 막대에는 접기 슬라이더, 펼치기·접기 재생, 이전·다음 단계만 남긴다
   - 단계별/한 번에, 속도, 보기 옵션, 선 긋기·면 표시, 설명(부피·겉넓이)은 막대 끝의 펼침 메뉴나 책 쪽 안으로 옮긴다
   - 안내 문장("같은 색 모서리끼리 만나요…")은 책 쪽에 인쇄된 글처럼 넣는다
2. **카메라가 가려지지 않는 영역에 도형을 맞춘다**
   - 왼쪽 패널과 아래 막대의 실제 크기를 재서, 남은 영역의 가운데에 도형이 오게 한다 (예: `camera.setViewOffset` 또는 target 이동 + 거리 보정)
   - 1번으로 막대가 얇아지면 보정 폭도 작아진다
3. **책을 화면 가득**: 빈 책과 도형 장면 모두 책이 화면 대부분을 차지하게 카메라 거리를 줄인다. 차례·안내 글이 읽히는 크기여야 한다
4. **차례로 돌아갈 때 확인**: 만든 도형이 있으면 "만든 도형이 사라져요" 확인을 띄우거나, 마지막 도형을 기억해 두었다가 돌아오게 한다
5. **작은 버그**: 보기 메뉴 바깥 클릭·Esc로 닫기, 왼쪽 패널 제목 줄에 불투명 배경
6. **챗봇을 그림책 톤으로**: 종이 색 배경, 책 글꼴, 말풍선. 열려도 도형과 단계 점을 가리지 않는 자리에 둔다
