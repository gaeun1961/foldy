## 요약
- 사진 인식(LLM) 없이 쓰는 기본 길 "직접 만들기"를 업로드 아래에 두었다. 두 가지를 토글로 고른다
  - **치수로 만들기**: 도형 드롭다운(직육면체/정육면체) + 치수 슬라이더 → 십자형 전개도. 도형이 없을 때는 "이 치수로 만들기", 있으면 슬라이더를 움직이는 대로 바로 바뀐다
  - **전개도 그리기**: 칸 위를 끌어서 직사각형을 그리면 면 하나, 면을 누르면 지운다, "모두 지우기". 그린 대로 grid 전개도가 되어 바로 3D로 보이고 접힌다. 정육면체·직육면체·잘못 그린 전개도 모두 된다
- 사진 인식 결과가 오면 십자형은 치수 칸, 학습지 전개도(grid)는 그리기 칸에 채워져 이어서 고칠 수 있다
- 사진 인식이 실패하면 "아래에서 전개도를 직접 만들어 보세요"(눌러서 이동)로 안내한다

## 변경 범위
- `manualScene.ts`(새 파일): 도형·슬라이더 목록 데이터(`SHAPES`, 범위 1~10, 0.5 단위), `crossScene`(라벨이 없으면 ㄱ~ㅇ, 십자형 선은 남김), `gridScene`(모든 면이 같은 정사각형이면 정육면체, 아니면 직육면체, 치수는 면 변 길이에서), `rectOf`, `overlaps`
- `ManualInput.tsx`(새 파일): 치수로 만들기 / 전개도 그리기(SVG 칸, 12 × 9, 인식 전개도가 더 크면 늘림, 면 글자·색칠 표시)
- `App.tsx`: 직접 만들기 연결. 치수만 바꾸면 펼침·선을 그대로, 전개도를 새로 그리면 펼친 상태에서 새로 시작. 도형이 없을 때 안내 "학습지 사진을 올리거나 왼쪽에서 직접 만들어 보세요"
- `PhotoUpload.tsx`: 실패 안내를 직접 만들기로 이어지는 링크로
- `index.css`: 직접 만들기·그리기 칸, 왼쪽 영역 스크롤
- `manualScene.test.ts`(새 검사, `npm test`에 추가)
- 문서: `ui.md` 화면 배치 3번·안내 문구, TODO-12 목표·완료 조건, 이슈 제목

## 결정
- 기본 길은 LLM 없이 **전개도 그리기**. 무료 한도·인터넷 문제와 상관없이 모든 학습지 문제를 옮길 수 있다. 정육면체 전개도 11가지 중 고르기는 목록에 없는 모양이 있고, 전개도를 머릿속으로 못 접는 학생에게 고르기가 오히려 어려워서 하지 않았다
- 그리기는 칸 단위 직사각형이라 직육면체(면 크기가 다른 전개도)도 그릴 수 있다. 다른 면과 겹치게는 못 그린다(빨간 미리보기)
- 다른 도형(정다면체, 원기둥·원뿔)은 `SHAPES` 목록에 한 줄씩 더하면 드롭다운과 슬라이더가 생긴다
