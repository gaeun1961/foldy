## 요약
- 아래 패널: 안내 한 줄 → 공식 탭 → 접기(슬라이더, 이전·다음 단계, 접기/펼치기) → 선 긋기·선 지우기 / 보기·차례. 단계별/한 번에, 속도, 면 표시, 다른 전개도 보기는 보기 메뉴로
- 스타일: 종이 스타일(크림색, 갈색 테두리)도 만들어 봤지만, 팀원과 이야기해 정하기로 하고 파스텔 클레이(#104)로 되돌렸다
- 공식 결과는 아래 노란 박스 대신 왼쪽 쪽에, 끝난 뒤에만. 제목·한 줄 설명·결과 중 결과가 설명 자리를 대신한다
- 카메라를 수평 약 40°에서 62°로 올렸다. 위치 관계 모서리를 다른 화면과 같은 굵기로, 연장선은 책 페이지 안에서 끝나게
- backend 가 꺼져 있으면 빨간 오류 없이 부드러운 안내만. README 에 시연 순서

## 결정
- 입체로 보는 설명은 책을 그 범위에 맞춰 다시 만든다 (#111). 전개도 크기의 책에서는 접은 도형이 작아 보이고 닮음의 큰 도형이 책 밖으로 나갔다
- 공식 결과가 왼쪽 쪽에 나오므로, 공식을 고르면 왼쪽 위 카드를 접고, 전개도로 보는 설명은 카메라가 왼쪽 쪽 글까지 담는다. 대신 그 화면에서는 전개도가 작게 보인다
- 왼쪽 쪽 글이 바뀌어도 3D 를 다시 만들지 않고 책 그림만 다시 그린다 (카메라·설명 진행 유지)
- 최단 거리 점 고르기는 하지 않았다. 직육면체에서 같은 면에 없는 꼭짓점 쌍은 서로 정반대인 네 쌍뿐이고 답이 모두 같아서, 꼭짓점 고르기는 의미가 없다. 모서리 위 아무 점을 고르려면 계산을 새로 만들어야 한다

- 겉넓이·부피·닮음·위치 관계를 모든 다면체로 넓혔다. 겉넓이는 마주 보는 면 대신 같은 모양 면끼리(각뿔·정사면체는 마주 보는 면이 없다), 접힌 입체에서 칠한다. 대각선·최단 거리는 상자만 둔다 (사용자 결정)
- 부피: 각기둥은 밑면 판 층 쌓기, 각뿔은 같은 밑면·높이의 기둥에 세 번 붓기, 정다면체는 가운데로 모이는 각뿔로 나누기. 닮음: 빈틈없이 채울 수 없는 도형은 틀 옆에 작은 면 k²장, 작은 도형 k³개를 늘어놓는다. 붓기·늘어놓기는 나중에 원뿔·원기둥에도 같은 방식으로 쓴다

- 처음에는 왼쪽 쪽을 읽기 전용으로 두고 공식 탭을 아래 패널에 뒀다가, 사용자 결정으로 공식과 다른 전개도 보기를 왼쪽 쪽 메뉴로 옮겼다. 왼쪽 쪽이 늘 보여야 해서 평소 카메라도 왼쪽 쪽 글까지 담는다(그만큼 전개도가 작아진다)

## 기술 문제
- 공식을 켠 채 드롭다운에서 공식이 없는 도형(정다면체 등)으로 바꾸면 공식 탭·접기 버튼이 모두 사라졌다. 도형을 바꾸면 공식을 끈다
- 모서리 길이 글자의 높이를 앞 오른쪽에 두면 위에서 내려다볼 때 세로 글자와 겹쳐서 앞 왼쪽으로 옮겼다
