## 요약
- 앱을 열 때(새 탭·창) 빈 책 장면 위에서 약 10초짜리 팝업북 오프닝을 보인 뒤 그대로 빈 책 화면이 된다. 장면을 새로 만들지 않아 끝난 모습이 빈 책과 똑같다
- 흐름: 표지가 열림 → 빈 종이 5장이 휘며 넘어옴 → 도형 11개가 2~3개씩 들쭉날쭉 떠올라 곡선을 그리며 날아다님 → 속표지("foldy 입체도형 팝업북")가 넘어가기 시작하면 도형이 흡수됨(오른쪽 도형은 책 가운데로 길게 늘어나 빨려 들어가고, 왼쪽 도형은 아래로 가라앉음) → 차례가 드러남
- 새로고침하면 다시 보이지 않고(sessionStorage), 주소에 `?opening`을 붙이면 다시 본다(시연용). "건너뛰기" 버튼, 움직임 줄이기 설정이면 보이지 않음

## 변경 범위
- 3D 뷰어: `opening.ts` 새 모듈, `EmptyBook`에 `opening`·`onOpened`, 책 장면에서 표지를 책등에서 두 장으로 나눔
- UI: `App.tsx` 오프닝 상태·건너뛰기 버튼, 오프닝 중 패널 숨김(`index.css`)
- 문서: `viewer.md` "오프닝" 절, `ui.md` 오프닝, `01-folder-architecture.md`

## 주요 변경 파일
- `frontend/src/viewer/opening.ts`: 시간표·모양 상수는 맨 위에 모아 숫자만 바꿔 조정한다 (`TURN`, `POP_AT`, `SIZES`, `HEIGHTS`, `LOW_ANGLE`, `ABSORB_TIME`, `REACH` 등)
- `frontend/src/viewer/EmptyBook.tsx`: 오프닝 시계(프레임마다 최대 1/30초씩 더함), 낮은 카메라 각도에서 원래 각도로 올라가기, 오프닝 동안만 그림자
- `frontend/src/viewer/bookScene.ts`: 표지 두 장, `page`·`leftCover`·`thick`·`gutter` 내보내기, `pageTexture`·글꼴·색 상수 export
- `frontend/src/ui/App.tsx`, `frontend/src/index.css`

## 결정과 이유
- **넘기는 종이**: KOKUYO "Turn the page" 레퍼런스 C 구간 분석(바로 출발해 후반 감속, 휨 0 → 최대 → 0, 책등 쪽이 앞서고 바깥 끝이 뒤처짐)을 따르되, 레퍼런스처럼 45°에서 멈추지 않고 눕힌다. 다음 화면이 책 페이지라서
- **책등에서 각지지 않게**: 평평한 판 대신 48칸 평면을 매 프레임 휘고, 누웠을 때 책 장면의 골 기울기(`atan(2·dip/curl)`)를 이어 붙인다. 시작 높이는 휜 모양이 올라오는 높이를 재서 맞춘다(안 맞추면 속표지가 페이지 아래로 꺼져 차례가 비쳤다)
- **흡수 시각**: 책등을 축으로 도는 종이가 도형 방향(θ)에 닿는 시각을 넘김 각도 식을 거꾸로 풀어 구하고, 그 전에 끝나게 한다. 그래서 넘어가는 종이가 도형을 뚫지 않는다
- **늘이기**: 도형을 바깥 그룹(holder)에 넣어 holder 가 방향·비균일 크기를, 안쪽 mesh 가 스스로 도는 회전을 맡는다. 돌면서도 빨려 가는 방향으로 늘어난다
- **흰 종이 묶음이 갑자기 생기던 것**: 왼쪽 종이 묶음은 종이가 다 내려앉은 뒤에만 두꺼워진다(내려앉은 종이가 윗면을 덮고 있어 안 보인다)
- **그림자**: 오프닝 동안만, 도형과 넘기는 종이만 드리운다. 책은 드리우지 않아 끝나고 그림자를 꺼도 빈 책 모습이 같다
- **확인 방법**: headless Chrome(소프트웨어 렌더러)에 rAF 시계를 바꿔 끼워 원하는 시각의 장면을 찍어 확인했다. 실제 화면 속도·느낌은 사용자가 `npm run dev`로 보며 조정했다

## 리스크/이슈
- 소프트웨어 렌더러에서는 프레임이 느려 오프닝이 길어진다(시계가 프레임마다 최대 1/30초라 단계를 건너뛰지는 않는다)
- 가운데에 가까이 떠 있던 도형은 책 가운데까지 거리가 짧아 늘어나는 게 덜 보인다
