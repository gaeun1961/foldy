## 결정
- 슬라이더는 그대로 전체 펼침 값 `s` 하나다. 단계별일 때는 뷰어가 `s`를 `n`칸으로 나눠 k번째 칸에서 k번째 면을 접는다 (`stepUnfold`). 그래서 챗봇 화면 조작(TODO-10)도 값 하나만 보내면 된다
- 단계 사이 멈춤·속도·이징은 UI가 `unfold`를 바꾸는 방식으로 만든다. 뷰어는 값만 받는다 (TODO-3과 같은 원칙)
- 강조는 뷰어가 값에서 정한다: 진행률이 0과 1 사이인 면을 강조하고, 단계 사이에 멈춰 있으면 마지막에 움직인 면을 계속 강조, 다 펼치거나 다 접으면 끈다. 방향(접기·펼치기)을 따로 받지 않아도 된다
- 회전축 굵게는 WebGL 선 굵기가 1로 고정이라 얇은 원기둥 메시를 pivot에 붙였다. 축 위에 있어서 회전해도 그 자리다
- 속도: 한 번에 모드 끝까지 5 / 3 / 1.5초, 단계별 한 단계 1.8 / 1.2 / 0.7초 + 멈춤 0.7 / 0.5 / 0.3초

## 추가 (2026-10-21, 같은 PR)
- 접는 순서를 **왼쪽 → 뒷면 → 오른쪽 → 윗면 → 아랫면**으로 바꿨다. 뒷면이 오른쪽 면 끝에서 먼저 일어서고, 오른쪽 면이 접히며 뒷면을 덮개로 얹는다. 자식(뒷면)이 부모(오른쪽)보다 먼저 접히므로 "부모가 먼저" 규칙을 빼고, 검사는 "자기와 조상이 모두 접힌 면은 입체 좌표"로 바꿨다
- 카메라 범위: 한 단계를 8칸으로 나눠 중간 모양을 담는다. 4×2×3 직육면체에서 단계별 가장 높은 곳이 6.00 → 4.46, 범위 구 반지름(단계별만)이 7.57 → 7.30. 카메라는 "한 번에" 모드(7.47)까지 같이 담아서 방식을 바꿔도 움직이지 않는다. 처음 버전(펼침·접힘만, 7.02)보다는 약 6% 작게 보인다
- 상태 배지: 버튼 애니메이션 중에는 숫자 없이 "직육면체 · 접는 중", 멈추면 숫자. `FoldControls`가 `onPlayingChange`로 알린다
- `AGENTS.md`에 "답변과 문서는 한국어로", README에 backend 검사 명령과 ruff 설치(`requirements.txt`에 포함)
