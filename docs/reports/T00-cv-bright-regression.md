## 문제와 변경

사용자 캡처의 문제 영역(363×140)에서 도형 셋 모두 추천되지 않았다. 현재판은 색상·밝기 마스크 3,926픽셀이 opening 후 0이 됐다. 최초 CV도 4,456→0이었다. 캡처 재현에서 확인한 원인이며 원본 촬영이나 사용자의 실행 주소까지 동일하다는 뜻은 아니다.

기존 마스크에 밝은 색칠을 검출하는 채널 차이 조건을 추가했다. 노란 면을 빨간 채점으로 오인하지 않도록 구분하며, 경계 선명도는 RGB 최대·최소 채널 양쪽으로 계산한다. 기존 위치·면적·모폴로지·병합·회전 규칙은 유지했다. 모델·의존성 추가는 없다.

기존 UI에서 `문제 없이 도형만`은 추천을 건너뛰었다. 두 진입 경로를 공통 함수로 연결하고 문제 선택 버튼을 `선택한 문제에서 도형 찾기`로 바꿨다. 자동 추천 0개는 실패 안내와 수동 선택 안내를 표시한다. 두 단계 선택은 유지하며 AI 호출 정책·지원 도형은 바꾸지 않았다.
