  - 결과가 오면: 펜이 오른쪽 쪽 전개도를 칠해 내고(여러 도형이면 ①부터 차례로), 왼쪽 쪽으로 건너가 제목·문제 글을 써 낸 뒤 들려 사라진다 (하나면 약 2초)

- 실측용 계측기 `?perf` (fps·가장 느린 프레임·사진 읽기 시간)

## 결정 (바뀐 것)
- **카드 → 책**: 처음에는 만들기 카드의 "인식한 전개도 그림"에 펜 연출을 넣었으나, 아이 시선은 3D 책에 있으므로 카드 연출은 빼고 책에서 그린다 (사용자 결정). 카드 그림은 연출 없이 그대로
- **시간을 정하지 않는다**: 인식 시간은 사진·도형 수마다 다르다(1개 약 28초, 2개 약 50초). 기다리는 동안은 되풀이하고, 결과가 오면 빠르게(0.45~0.7초/전개도) 끝낸다
- **여러 도형은 책 안에 맞추기**: `lab/book-pen.html`에서 "책 안에 맞추기"(pageSlots)와 "띄워서 크게"(책 위 공중에 기울인 판)를 비교한 뒤, 책 안에 맞추기로 결정. 배치·고르기는 사진 세션이 `gallery`로 구현(9ff4b5f, e2d90ca)하고 펜은 칸 순서대로 한 번에 그린다
- **색**: 펜 몸통 `--accent` 청록 계열, 끝 `--peach`, 깎은 나무 종이색, 촉 `--ink`. 칠은 원래 면 색 (사용자: "색상은 원래 채워주던 색상")

## 기술 (해결한 문제)
- **전개도 가리기**: 면·모서리·선·표시 재질에 `onBeforeCompile`로 가림 셰이더를 덧씌운다. 정점의 월드(또는 판) 좌표 x·z로 가림 그림(캔버스 512, 펜 길을 굵은 흰 선으로 칠함)을 읽어 검은 곳은 `discard`. `pullTowardCamera` 같은 기존 `onBeforeCompile`과 겹쳐 쓰고 `customProgramCacheKey`를 구분한다. Sprite(꼭짓점 라벨)는 셰이더가 달라 그리는 동안 숨겼다가 끝나면 보인다
- **왼쪽 쪽 글**: 같은 페이지 크기의 빈 쪽 그림(`pageTexture(..., [])`)과 글 있는 쪽 그림을 가림 그림으로 섞는다 (`map_fragment` 뒤에 mix)
- **색연필 결**: 매 프레임 SVG `feTurbulence`를 계산하면 브라우저가 멈췄다(카드 버전). 결 무늬를 한 번만 그린 작은 캔버스(/ 방향 짧은 빗금)로 바꿔 끝자락 칠에만 패턴으로 쓴다
- **그리기를 건너뛰던 버그**: 내 학습지를 열면 사진·위치가 뒤따라 바뀌어 뷰어가 곧바로 다시 만들어지는데, 처음 만들 때 "그렸음"을 적어 두 번째에 그리지 않았다 → 다 그린 뒤에 적고, 그리는 중 다시 만들어지면 처음부터
- **그림자가 먼저 보임**: 그림자 지도는 가림 셰이더를 안 타서 전개도보다 그림자가 먼저 책에 비쳤다 → 그리는 동안 `castShadow`를 끄고 그 전개도를 다 칠하면 켠다 (78aa3da)
- **첫 프레임 멈춤에 그림이 건너뜀**: 장면 만들기·셰이더 첫 컴파일 두 프레임이 PC에서도 약 0.55초 → ① 이 다 그려진 채 나왔다. 펜 시계를 두 프레임 뒤부터 잰다 (78aa3da)
- **같은 git 인덱스**: 두 세션이 같은 작업 폴더라 섞인 파일은 HEAD + 자기 줄만으로 blob 을 만들어 스테이징하고(`git hash-object` + `update-index`), 그 스냅샷을 임시 폴더에 꺼내 build·lint·test 를 돌린 뒤 커밋했다

## 리스크/이슈
- 화면이 바뀌는 순간의 멈춤(0.55초)은 남아 있다. 휴대폰에서는 더 길 수 있다
- 읽는 중에는 사진을 쪽 가운데에, 결과에서는 인식된 자리(photoBox)에 깔아 사진이 한 번 옮겨 간다. 카메라 구도도 빈 책(두 쪽 전체) → 전개도 쪽으로 툭 바뀐다
- 가림 셰이더는 재질마다 따로라, 여러 도형은 재질을 공유하면 안 된다 (사진 세션이 전개도마다 따로 만듦)
- 오프닝·설명 모드 중에는 그리지 않는다 (설명 모드면 건너뜀)
