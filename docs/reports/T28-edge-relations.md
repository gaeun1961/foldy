## 요약
- 설명 모드에 **위치 관계**(`'edge-relations'`, 바로 세운 입체)를 더했다. 기준 모서리(빨강)에 대해 평행(초록) → 만남(주황) → 꼬인 위치(보라)를 한 종류씩, 종류 안에서는 모서리를 하나씩 보인다. 지난 종류는 연하게 남는다
- 색만으로 구분하지 않는다: 평행은 두 모서리를 품는 반투명 평면, 만남은 만나는 점과 직각 표시, 꼬인 위치는 점선 막대와 두 모서리를 양쪽으로 늘린 점선 직선. 늘린 직선은 끝까지 본 뒤에도 남는다
- 3D 뷰에서 다른 모서리를 누르면 그 모서리가 기준이 된다 (`LessonObject.pickTargets`/`pick`, 뷰어 안 상태)
- 만남까지 보고 멈추면(꼬인 위치 직전) "남은 모서리는 빨간 모서리와 만나지 않아요. 그럼 평행일까요?"를 묻는다 (`lessonHint`)
- 멈춘 뒤 `평행 3 + 수직으로 만남 4 + 꼬인 위치 4 = 나머지 모서리 11개`
- 맞닿는 모서리 색(TODO-22)은 설명 모드에서 이미 숨겨지므로 동시에 켜지지 않는다

## 설계 근거 (조사 2026-10-30, 근거 강도는 약함)
- 평면에서 배운 "만나지 않으면 평행"이 공간에서 오개념이 된다. 구분 기준은 "같은 평면 위에 있는가" → 평행에 두 모서리를 품는 평면을 띄우고, 꼬인 위치 직전에 "그럼 평행일까요?"를 묻는다 — 남진영·조성민 (2013), 한국수학교육학회지 시리즈E 27(1), [koreascience](https://koreascience.or.kr/article/JAKO201318450946039.page)
- 고학년에서도 꼬인 위치 오개념이 남고, 직선이 끝없이 뻗는다는 것을 놓친다 → 모서리를 점선 직선으로 늘린다 — Doğan (2013), 석사논문, [Balıkesir Univ.](https://acikerisim.balikesir.edu.tr/items/597e2b93-39b8-4ff9-ab29-db3c67684522/full)
- 교육과정: 중학교 1~3학년군 '기본 도형'(점, 직선, 평면의 위치 관계). 교과서 관행상 중1
