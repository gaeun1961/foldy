## 알아낸 것 (안 되는 것)
- 생각 단계는 이미 가장 낮은 `low` 라 더 줄일 곳이 없다 (`agy models`)
- stream-json 입력의 내용 칸은 `text` 만 받는다 → 사진을 바로 넣어 read_file 왕복(약 5초)을 없애는 것은 CLI 로는 안 된다 (API 엔진은 사진을 바로 넣는다)
- 미리 띄운 agy 는 backend 가 죽으면 입력이 닫혀 0.5초 만에 스스로 끝난다 (`--reload` 로 다시 떠도 남지 않음)
