## 결정
- **좌표 맞추기**: 전개도 grid 좌표 (x, y)는 `gridPolyhedron`에서 펼친 좌표 (x, −y, 0)이고 루트 면은 접지 않는다. 그래서 사진 판을 면 트리 루트(`tree.root`)의 자식으로 같은 좌표에 두면 따로 계산하지 않아도 칸 1개 = 길이 1로 겹치고, 접어도 사진은 바닥에 남는다
- **사진 크기·비율**: 칸의 SVG `<image>`처럼 정사각형(처음 12칸 × 배율) 안에 비율대로 넣는다. 회전은 칸에서 보이는 시계 방향 그대로
- **높이**: 사진은 페이지 윗면과 같은 높이에 두고 `polygonOffset`(−2)으로 페이지보다 앞에 그린다. 전개도와의 간격은 페이지와 같은 1%라 새 깜빡임이 없다
- **페이지 크기**: 사진 정사각형까지 담게 늘린다. 사진이 페이지 밖 공중에 뜨지 않고, 책등 쪽 골(여백 안쪽)에도 걸리지 않는다
- 사진은 `net.layout = "grid"`일 때만 깐다 (치수로 만든 십자형은 사진과 위치가 맞지 않음)
- 사진 위치를 바꾸면 3D를 다시 만든다 (페이지 크기가 바뀌므로). 카메라도 처음 구도로 돌아간다
- **종이 결**: 단면 텍스처에 줄을 열다섯 개쯤만, 굵은 진한 줄 + 밝은 줄로 그린다. 촘촘하면 한 색으로 뭉개지고, 밉맵을 끄면 축소할 때 지그재그로 깨졌다

## 리스크/이슈
- 사진이 크면(정사각형 12칸 이상) 페이지가 커져서 왼쪽 페이지 글이 화면 밖으로 밀린다
- 사진 비율과 상관없이 정사각형으로 페이지를 늘려서 가로로 긴 사진은 위아래 여백이 생긴다 (사진을 먼저 읽어야 알 수 있어 그대로 둠)
- 실제 휴대폰 사진(원근 왜곡)은 칸과 완전히 맞지 않는다. 크기·방향만 맞출 수 있다
