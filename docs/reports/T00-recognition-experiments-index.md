## 판단

상위 모델을 유지하며 전체 문제 문맥·일관된 지원 범위·형식 보정·기하 검사를 적용한 실험에서 H01/A04/C01 모두 정확히 표시됐다. 교사 예시가 없는 조건도3/3이고 예시2개 조건도3/3이어서 예시 추가의 정확도 이득은 확인되지 않았다. 입력 토큰은8456→16604로 증가했다. 예시는 오류 개선 효과를 확인한 경우에만 선택적으로 적용한다.

## 코드와 자료

`backend/evals/bank50_*`: 선정·정리·같은 예시 재현·보고서 제작.

`backend/evals/flow10*`: 10건 API 비교, HTML 보고서·원인 분석.

`backend/evals/flow3_server.py`, `flow3_browser.cjs`, `flow3_browser_body.txt`: 같은 상위 모델의0/2예시 비교 서버와 실제 Viewer 브라우저 계측. `flow3_report.py`는 보고서 생성기다.

**스크립트는 당시 Windows 환경의 실행 스냅샷이다.** 경로가 고정되어 있으므로 다른 팀원 컴퓨터에서 그대로 실행하지 말고, 각 파일 상단의 저장소·자료·Playwright·Chrome 경로를 먼저 조정한다. repo의 현재 `main`과 다른 실험 기준 커밋은 `9cbdde6`이다. 최신 서비스와 동일하다고 가정하지 않는다.

원본 자료 폴더는 작성자 PC의 `D:/가천대학교/26-2/해커톤/_테스트 학습지/퓨샷/`이다. 사진·전체 모델 원문·정답 라벨은 로컬에 보관하며 Git에는 포함하지 않는다. 자료가 필요한 팀원은 별도 전달 경로로 받아야 한다. 코드만 받으면 시험 이미지가 자동으로 생기지는 않는다.

`flow3_server.py`는 backend `.env`의 `LLM_API_KEY`를 읽는다. 키 파일은 커밋하지 않는다. 브라우저 하네스를 실행하면 실제 유료 모델 호출이 발생한다. 이 실험에는 무조건 켜는 자동 테스트를 추가하지 않았다. 8768(API),5194(Vite) 포트를 사용한다.

`bank50_seen.py`는 해당 실험의 날짜 제한을 보존하므로 이후 실행 시 새 호출을 시작하지 않는다. 재실행하려면 입력·기준·예산·마감부터 새로 정해야 한다. 기존 결과 폴더에 덮어쓰지 않는다.

## 검증 범위

실험 Python 린트·포맷, 로컬 저장 응답에 대한 형식·기하 회귀 검사, HTML 이미지·링크·모바일 넘침, 실제 Viewer onReady를 확인했다. 제품 코드 변경이 없어 전체 제품 테스트나 PR 머지 검증을 수행한 것으로 주장하지 않는다. 원본 보고서의 기기·계측 장애·모델 별칭·실험 한계도 함께 읽는다.

#162의 전체 독립 심사·전체 자료 평가를 완료했다는 의미가 아니므로 이슈를 닫지 않는다.
