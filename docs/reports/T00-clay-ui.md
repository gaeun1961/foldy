# 작업 기록 - 바·버튼 파스텔 클레이 입체 스타일

- 일시: 2026-10-30 22:04 (KST)
- 작성자: HandoA01
- 에이전트: Claude Code
- 작업 유형: UI 스타일 변경 (결정 변경: 강조색)

## 요약
- 아래 바·만들기 카드·버튼을 납작한 흰 패널에서 파스텔 클레이 느낌의 입체로 바꿨다. 빛은 왼쪽 위에서 오고, 판은 오른쪽 아래로 두께와 길고 부드러운 그림자가 보인다. 바·카드는 반투명(70~75% + 뒤 흐림)이라 3D 책 장면이 은은하게 비친다
- **결정 변경**: UI 강조색을 시안의 파랑(#3D6FD9)에서 차분한 청록(#3A7D87)으로 바꿨다. 파스텔 레퍼런스(크림·민트·청록·살구)에 맞추고, 책 장면의 세이지 초록 매트와도 어울린다. 흰 글씨 대비는 4.2:1 이상으로 유지
- 버튼·문구의 이모지를 뺐다 (AI가 만든 티가 난다는 피드백). 챗봇 아이콘은 단색 말풍선 선 그림(SVG). 상태 배지의 ✔/✖, 닫기 ✕, 면 표시 기호(◎ ● ★)는 기호라서 남김

## 변경 범위
- CSS만 바꿨다. 동작·컴포넌트 구조는 그대로
- 3D 뷰어 안의 색(등분점 파랑 등)은 건드리지 않았다

## 주요 변경 파일
- `frontend/src/index.css`: `:root`에 `--slab`, `--panel-shadow`, `--face`, `--raised`, `--pressed`, `--accent-face`, `--accent-raised`, `--groove`, `--peach`. 볼록한 버튼 공통 규칙 하나로 모음 (누르면 안으로 들어감). 토글 묶음·슬라이더 트랙은 민트 홈, 슬라이더 손잡이는 흰 원판
- `frontend/src/ui/*.tsx`: 이모지 제거, 챗봇 아이콘 SVG
- `docs/specs/ui.md`: 색 기준(패널 배경, 강조색, 입체감, 아이콘) 갱신, 버튼 이름의 이모지 제거

## 리스크/이슈
- `backdrop-filter`가 무거운 기기에서는 3D와 함께 느려질 수 있다. 느리면 `--slab` 불투명도를 올리고 흐림을 줄인다
- 좁은 화면(1024px 미만)은 spec대로 불투명 패널이라 입체 그림자가 없다
