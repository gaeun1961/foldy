## 결정
- backend 주소는 `api.ts`의 `API_URL` 상수(`http://localhost:8000`, api.md 기본 주소) 하나로 둔다. 사진 업로드(TODO-11)도 이 파일에 호출을 더하면 된다. backend CORS가 `localhost:5173`만 허용하므로 dev 서버는 5173으로 띄워야 한다
- 에러 문구: backend가 준 `detail`(예: 502 "답변을 가져오지 못했어요…")을 그대로 보이고, 연결 자체가 안 되면 "선생님과 연결이 안 됐어요. 잠시 뒤 다시 물어봐 주세요"를 보인다. 개발자용 원인은 콘솔에 남긴다
- 대화는 `ChatPanel`의 상태라서 창을 닫았다 열어도 남고, 새로고침하면 사라진다. backend도 대화 기록을 받지 않는다(한 질문씩)
- 좁은 화면 시트에는 닫기(✕) 버튼이 있어서 시트가 열려 있을 때 동그란 아이콘은 숨긴다

## 확인
- dev 서버(5173) + backend(8000, Gemini 키)를 띄우고 헤드리스 크롬을 CDP 스크립트로 조작했다: 아이콘 누르기 → "ㄱ이랑 만나는 꼭짓점은 어디야?" 입력 → 보내기 → "생각하는 중…" → Gemini 답 말풍선. 1280×860과 390×844(휴대폰) 둘 다 확인
- backend를 끄고 같은 순서로 보내 에러 말풍선이 나오는 것을 확인했다
- 도형이 없는 상태는 지금 화면에서 나오지 않는다(항상 목 데이터). TODO-11에서 도형이 없는 시작 상태가 생기면 확인한다
