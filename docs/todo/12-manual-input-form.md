## 완료 조건
- [ ] 조작 패널에 도형 드롭다운(직육면체/정육면체)과 치수 슬라이더가 있다 (`docs/specs/ui.md` 화면 배치 3번)
  - 직육면체: 가로·세로·높이 슬라이더 3개. 세로는 `size.depth`에 들어간다
  - 정육면체: 한 변 슬라이더 1개 (`size: { edge }`)
- [ ] 슬라이더를 움직이면 뷰어가 바로 바뀐다. 현재 값이 슬라이더 오른쪽에 숫자로 보인다
- [ ] 사진 인식 결과(TODO-11)가 오면 드롭다운과 슬라이더가 그 값으로 채워지고, 학생이 이어서 고칠 수 있다
- [ ] 슬라이더 최솟값은 0보다 크다. 범위와 눈금 단위를 정해서 코드 주석에 적는다
- [ ] 처음부터 만든 도형은 `lines`가 빈 배열이고 `net`은 `cross`다. 라벨이 없으면 기본 라벨 ㄱ~ㅇ을 채운다 (꼭짓점 라벨 기본 표시, `docs/specs/ui.md`)
- [ ] 다른 도형(정다면체, 원기둥·원뿔)은 1차 범위 밖이다. 나중에 넣기 쉽게 드롭다운 선택지와 도형별 슬라이더는 목록 데이터로 둔다

- [ ] **전개도 그리기**: 칸(격자) 위를 끌어서 직사각형을 그리면 면 하나가 생긴다. 면을 누르면 지운다. "모두 지우기". 그린 대로 grid 전개도(`net.layout = "grid"`)가 되어 바로 3D로 보이고 접힌다. 정육면체·직육면체·잘못 그린 전개도 모두 그릴 수 있다
- [ ] 사진 인식 결과가 grid 면 전개도를 그리기 칸에 불러와 고칠 수 있다
- [ ] 사진 인식이 실패하면 안내가 이 영역(직접 만들기)을 가리킨다
