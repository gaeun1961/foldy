## 시안 화면 설명 (이미지를 못 보는 경우)

세로로 긴 화면을 위아래 두 부분으로 나눈다.

- **위쪽 3D 뷰 (화면 높이의 약 55%)**
  - 밝은 베이지색 배경에 원근감 있는 옅은 격자 바닥이 깔려 있다
  - 왼쪽 위에 흰색 둥근 알약 모양 배지가 떠 있고, "직육면체 · 접는 중 43%"라고 쓰여 있다. 다 접으면 초록 체크와 함께 "빈틈없이 사각뿔가 됐어요 · 만나는 선 4쌍"처럼 바뀐다
  - 전개도가 반쯤 접혀 있다
    - 가운데 면은 흰색이고, 옆면들은 하늘색·주황·보라·분홍 파스텔색이다
    - 면마다 동그라미 숫자(①~⑥)가 있다
    - 모서리는 빨강·초록·파랑·보라·노랑·청록으로 칠해져 있고, 접으면 맞닿는 모서리끼리 같은 색이다
- **아래쪽 조작 패널 (흰 배경, 세로 스크롤)**, 위에서부터
  1. 제목 "전개도 접기 실험실"(굵고 크게)과 회색 설명 한 줄 "전개도를 접어 보면서 어떤 선끼리 만나는지, 어떤 면끼리 마주 보는지 확인해 보세요."
  2. "입체도형" 라벨과 화면 폭 가득한 드롭다운(값: 직육면체)
  3. 치수 슬라이더 3개(가로 2.5 / 세로 1.5 / 높이 2.1)
     - 라벨은 왼쪽, 현재 값은 오른쪽 끝에 있다
     - 트랙은 굵은 파란색이고 손잡이는 동그랗다
  4. "접기" 슬라이더(오른쪽에 43%)
  5. 반반 나눈 큰 버튼 두 개: 왼쪽 "◀ 펼치기"(흰 바탕 테두리), 오른쪽 "접기 ▶"(파란 바탕 흰 글씨)
  6. (사각뿔 시안) 체크박스 목록: 한 면씩 차례로 접기 / 만나는 선을 같은 색으로 / 면 번호 보기 / 반투명하게 보기

## 가져갈 것

- **화면 구성**: 위쪽 3D 뷰, 아래쪽 조작 패널
- **상태 배지**: 3D 뷰 왼쪽 위에 "도형 · 상태 · 진행률"
  - 예: "직육면체 · 펼친 상태", "직육면체 · 접는 중 43%", "✔ 빈틈없이 직육면체가 됐어요"
  - 도형 이름에 맞게 조사(이/가)를 붙인다. 시안의 "사각뿔가"는 틀린 것이다
- **조작 요소**
  - 도형 선택 드롭다운
  - 치수 슬라이더: 직육면체는 가로·세로·높이, 정육면체는 한 변. 값은 오른쪽에 숫자로 표시
  - 접기 슬라이더: 0~100%, 뷰어의 `s`와 같은 값
  - 큼직한 "◀ 펼치기" / "접기 ▶" 버튼
- **맞닿는 모서리 색**: 접었을 때 맞닿는 모서리 한 쌍을 같은 색으로 칠한다 (규칙은 [viewer.md](viewer.md))
- **눈높이**
  - 큰 글씨: 본문 16px 이상, 제목 24px 이상
  - 큰 버튼: 높이 48px 이상, 터치 영역 44px 이상
  - 밝고 부드러운 배경(옅은 베이지 3D 뷰 + 흰 패널)
  - 친근한 존댓말 문구("~해 보세요", "~됐어요")

## 바꿀 것

- **면 색**: 면은 흰색이나 연한 회색 하나로 통일하고, **색은 맞닿는 모서리에만 쓴다**. 면 색과 모서리 색이 섞이면 어느 색이 무엇을 뜻하는지 헷갈린다
- **라벨**: 면 번호(①~⑥) 대신 **꼭짓점 라벨(ㄱ, ㄴ, ㄷ…)** 을 기본으로 보여준다 (`vertexLabels`). 면 번호는 보기 옵션으로만 둔다
- **전개도 배치**: 시안의 배치를 따르지 않고 [shape-scene.md](shape-scene.md)의 `cross` 배치([왼][앞][오][뒤] 한 줄, 위·아래는 앞면에)를 따른다
- **안내 문구**: 3D 뷰 아래쪽에 짧은 안내를 한 줄 띄운다
  - 예: "같은 색 모서리끼리 만나요", "점 두 개를 눌러 선을 그어 보세요"(선 긋기 모드), "사진을 올리면 도형이 나타나요"(도형 없음)
- **색만으로 구분하지 않기**: 색을 구분하기 어려운 학생도 있으므로, 맞닿는 모서리를 고르면(누르면) 짝 모서리가 함께 굵어지거나 깜빡이게 한다

## 화면 배치 (모바일 세로 기준)

위에서 아래 순서. 3D 뷰는 위에 고정하고, 패널만 스크롤한다.

| 순서 | 영역 | 내용 |
|---|---|---|
| 1 | 3D 뷰 (높이 약 50%) | 상태 배지(왼쪽 위), 안내 문구(아래쪽), 화면 돌리기·확대 |
| 2 | 사진 업로드 | 패널 맨 위. "학습지 사진 올리기" 큰 버튼(카메라 촬영 또는 앨범), 인식 중·실패 상태 표시. 실패하면 바로 아래 3번으로 안내 |
| 3 | 도형·치수 | 도형 드롭다운 + 치수 슬라이더. 사진 인식 결과로 채워지고, 학생이 직접 고칠 수 있다 (= 수동 입력 경로) |
| 4 | 접기 | 접기 슬라이더 + 펼치기·접기 버튼 |
| 5 | 선 긋기 | "선 긋기" 토글 버튼(켜면 3D 뷰에서 점 두 개를 누른다) + "선 지우기". 곡면 도형은 전개도 상태에서만 켜진다 |
| 6 | 보기 옵션 | 체크박스: 꼭짓점 라벨(기본 켬), 맞닿는 모서리 색(기본 켬), 면 번호, 반투명하게 보기 |
| 7 | 챗봇 | 화면 오른쪽 아래 떠 있는 "힌트 물어보기" 버튼. 누르면 아래에서 올라오는 시트(화면의 절반 높이)로 대화창이 열리고, 3D 뷰는 위에 계속 보인다 |

넓은 화면(가로 1024px 이상, 노트북·발표 화면)에서는 왼쪽에 3D 뷰, 오른쪽에 패널(2~6)을 두고, 챗봇은 패널 아래나 오른쪽 시트로 연다.

## 색 기준 (시작값)

| 용도 | 값 |
|---|---|
| 3D 뷰 배경 | 옅은 베이지 (#F5F3EF 근처), 옅은 격자 |
| 패널 배경 | 흰색 |
| 면 | 흰색 (#FFFFFF) 또는 연한 회색 (#ECEEF2), 살짝 반투명 가능 |
| 기본 모서리 | 진한 회색 |
| 맞닿는 모서리 | 서로 잘 구분되는 6~7색 (빨강, 주황, 노랑, 초록, 청록, 파랑, 보라 계열) |
| 강조(버튼, 슬라이더) | 파란색 (시안의 파랑 #3D6FD9 근처) |
| 완료 | 초록 체크 |
