# 기록 증류·정답 은행 (#161)

## 실패 집계

`python -m evals.distill --cases evals/cases --output evals/results/distill.json`은 원본을 바꾸지 않고 숫자만 출력한다. 추천 네모와 학생이 실제 읽은 네모를 IoU 0.5 이상으로 일대일 최대 매칭한다. 학생 선택은 사람 검수 정답이 아니므로 정탐/오탐/놓침 **대리 지표**다. 전체 사진 읽기(null)는 네모 정답에서 제외한다. 기록이 세션 단위라 재선택 전 중간 상태를 복원했다고 주장하지 않는다.

맞음/틀림은 세션의 마지막 피드백을 집계한다. 여러 읽기 중 어느 응답인지 연결되지 않은 옛 이벤트를 개별 인식 정확도로 세지 않는다. 읽기 성공/실패·시간·피드백 없는 세션을 별도로 집계한다. 파일이 깨졌으면 조용히 버리지 않고 invalid 수로 표시한다.

## 정답 은행

학생이 [맞음]을 누른 현재 결과만 해당 브라우저에 저장한다. 사진 자체는 저장하지 않는다. 도형과 문제 사진 모두 있어야 하며 각각 dHash 거리 0 **및 SHA256 완전 일치**를 요구한다. 같은 전개도에 숫자·문장이 다른 문제를 재사용하지 않기 위한 초기 기준이다. 비슷한 사진까지 허용하는 임계값 완화는 검수된 별도 평가 자료가 쌓인 뒤 한다.

은행은 기록 모드(개발 또는 VITE_RECORD=1)에서만 켠다. [틀림]은 현재 결과 키를 제거한다. 새 사진/취소/실패에 이전 결과 키를 붙이지 않는다. 키 생성·저장소 실패는 원래 인식 경로로 돌아간다. 최대 50개를 저장하고 오래된 항목부터 지운다. 저장된 결과는 화면에 "저장된 답"으로 표시한다. 학습지 보관함과 달리 사진을 보관하지 않는다.

## 추천 값 맞춤

알려진 실패 검사는 외부 manifest와 픽셀 JSON을 읽어 실제 `findShapeBoxes`를 실행한다. development에서만 TUNE 격자를 비교하고 heldout은 선택된 값에 한 번 평가한다. 결과는 제안이며 서비스 상수를 자동 변경하지 않는다. 검수 자료가 없으면 합성 자료 통과를 실제 학습지 정확도로 발표하지 않는다.
