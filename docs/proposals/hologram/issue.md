# 이슈 본문 초안

제목: `[기능] 아크릴 피라미드 홀로그램 보기 (제안, 팀 확인 요청)`
라벨: `3d`, `ui`

---

아래 바 "홀로그램" 버튼을 누르면 지금 도형이 휴대폰·태블릿용 4방향 홀로그램(아크릴 피라미드)으로 나오는 기능을 만들어 봤습니다. 기획안 범위 밖이라 합치기 전에 같이 확인 부탁드립니다.
도형별로 만들지 않고 **무대**(`viewer/stage.ts`, 장면 → 도형 물체)와 **3D 디자인 토큰**(`viewer/theme.ts`)으로 나눠서, 홀로그램은 도형을 모르고 비추기만 합니다. 책 화면은 색 숫자만 토큰으로 바뀌어 모습이 그대로입니다.
설명·명세·합치는 법: `docs/proposals/hologram/` (README, spec, api 초안). 확인할 것: 실물 아크릴 방향·크기, 휴대폰 세로 화면 버튼 자리, 다음 단계(책 화면이 무대 쓰기, 설명 모드 홀로그램)를 할지.
