# 홀로그램 명세 (제안, 팀 합의 전)

> 합의되면 "뷰어" 절은 `docs/specs/viewer.md`로, "화면" 절은 `docs/specs/ui.md`로 옮긴다. 개요는 [README.md](README.md).

## 뷰어

### `HologramViewer` (`frontend/src/viewer/HologramViewer.tsx`)

`viewer/index.ts`에서 export한다. `ViewerProps`와 따로인 컴포넌트다 (책 장면 `Viewer`는 그대로).

| prop | 기본 | 뜻 | 바뀌면 |
|---|---|---|---|
| `scene: ShapeScene` | | 그릴 도형. 다면체만 (`hologramSupported`) | 다시 만든다 |
| `center?: number` | `0.2` | 가운데 정사각형 한 변 ÷ 화면 짧은 변. 피라미드 꼭지 크기에 맞춘다 | 칸만 다시 배치 |
| `elevation?: number` | `20` | 카메라 높이각(도). 펼칠수록 45°까지 올라간다 | 다음 프레임 |
| `mirror?: boolean` | `false` | 좌우 반전. 실물에서 거꾸로 보이면 켠다 | 칸만 다시 배치 |
| `spin?: boolean` | `true` | 세로축으로 천천히 돌기 (0.35 rad/s) | 다음 프레임 |
| `fold?: boolean` | `true` | 접었다 펴기 반복. 끄면 접힌 입체 | 반복을 처음부터 |
| `showGuide?: boolean` | `true` | 가운데 정사각형 테두리(피라미드 놓을 자리) | 칸만 다시 배치 |
| `onTap?: () => void` | | 화면을 누르면 | |

`hologramSupported(scene)`: 면 트리로 접는 도형(직육면체·정육면체·정다면체 4종·각기둥·각뿔, 학습지 grid 전개도 포함)이면 `true`. 원기둥·원뿔·구는 아직 `false` (말기·회전체는 면 트리가 아니다).

### 화면 배치 (`holoLayout.ts`, three.js 없음)

- 좌표: 컨테이너 가운데가 원점, x 오른쪽, y 위 (픽셀)
- L = 컨테이너 짧은 변, c = `center` × L
- 가운데 c × c 정사각형은 검게 둔다. 둘레를 대각선으로 나눈 사다리꼴 4칸: 아래·오른쪽·위·왼쪽 (`regions(L, c)`)
- 칸마다 카메라 하나. 그 칸 쪽에 선 사람이 그 방향의 모습을 본다

| 칸 | 바깥 방향 | 카메라 (방위각) | 그 사람의 오른쪽 |
|---|---|---|---|
| 아래 | −y | 앞 +z (0) | +x |
| 오른쪽 | +x | 오른쪽 +x (π/2) | +y |
| 위 | +y | 뒤 −z (π) | −x |
| 왼쪽 | −x | 왼쪽 −x (−π/2) | −y |

- 반사 규칙 (뒤집은 피라미드, 45° 면): 칸의 **바깥쪽이 떠 보이는 도형의 위쪽**이다. 좌우는 그 칸 쪽에 선 사람의 오른쪽이 그림 오른쪽이다 (거울 면은 면과 나란한 방향을 바꾸지 않는다). `uvOf(region, L, c, p, mirror)`
- 렌더링: 칸마다 `WebGLRenderTarget`(가로 L × 세로 (L − c)/2, 기기 픽셀)에 그리고, 사다리꼴 메시에 텍스처로 붙인다. 사다리꼴 밖은 잘린다. 해상도 배율은 2까지 (휴대폰에서 한 프레임에 4번 그린다)
- 크기 맞추기 `fitDistance`: 도형이 돌고 접히는 동안 차지하는 구(반지름 R)가 칸 가운데 높이의 사다리꼴 폭 (c + L)/2와 그림 세로 중 작은 쪽의 95%에 들어가게 카메라 거리를 정한다. 세로 시야각 35°

### 도형과 움직임

- 접기는 책 장면과 같은 면 트리(`buildFaceTree`·`applyUnfold`·`stepUnfold`)다. 전개도를 바닥에 눕히는 자세(`layOnFloor`, 순서가 없는 도형은 `facingYaw`)와 접는 순서(`foldOrderOf`, 없으면 `farFirstOrder`)도 같다. 그래서 같은 전개도가 같은 순서로 접힌다
- 돌리는 축은 다 접은 입체의 가운데다
- 반복: 펼친 채 1.5초 → 한 면씩 접기(면당 0.9초) → 접힌 채 4초 → 한 번에 펼치기 1.5초
- 다 접히면 카메라가 입체 크기(R = 접힌 입체)로 다가가고, 펼칠수록 접는 전체 범위로 물러나며 높이각이 45°까지 올라간다. 바닥에 누운 전개도가 납작하게 보이지 않게
- 보이는 모습: 검은 배경, 면은 반투명 색(면마다 6색 돌려 쓰기, 바깥 0.35, 안쪽 0.25), 모서리는 굵은 흰 선(`Line2`, 화면 짧은 변 ÷ 220 px, 최소 2px). 꼭짓점 라벨·선·면 표시는 그리지 않는다 (작은 피라미드에서 읽히지 않는다)

## 화면

### 홀로그램 버튼

- 아래 바(`dock-row`)의 "차례" 바로 오른쪽. 모양은 차례와 같은 `contents-button`
- `hologramSupported(scene)`일 때만 보인다
- 누르면 홀로그램 보기를 연다

### 홀로그램 보기 (`frontend/src/ui/HologramMode.tsx`)

- 화면 전체(`position: fixed`, 검은 배경, 다른 패널 위)에 `HologramViewer`
- 열려 있는 동안 책 장면 `Viewer`는 그리지 않는다 (WebGL 화면 둘을 같이 돌리지 않게). 돌아오면 다시 만든다. 도형·펼침 값·설명 모드 등 App 상태는 그대로다
- 처음 열면 설정 판이 보인다. 화면을 누르면 설정 판이 열리고 닫힌다. Esc는 돌아가기 (전체 화면이 아닐 때)
- 설정 판 (책 화면 판과 같은 토큰: `--panel`, `--panel-shadow`)
  - 제목 "홀로그램", 안내 "휴대폰이나 태블릿을 눕히고, 가운데 사각형 위에 아크릴 피라미드를 뒤집어 올려요. 화면을 누르면 이 판이 열리고 닫혀요."
  - 슬라이더(`slider-row`): 가운데 5~45% (기본 20%), 높이 0~45° (기본 20°)
  - 켜고 끄기(`menu-button`, 켜지면 `--accent-face`): 접었다 펴기, 천천히 돌기, 놓을 자리, 좌우 반전
  - 전체 화면(`secondary-button`): 전체 화면 + 화면 꺼짐 방지(Wake Lock, HTTPS·localhost에서만). 누르면 설정 판을 닫는다. iOS Safari는 전체 화면이 없어 "홈 화면에 추가"로 쓴다
  - 돌아가기(`primary-button`): 전체 화면을 끄고 책 화면으로
- 설정은 기기에 남는다 (localStorage `foldy-hologram`). 기기마다 피라미드 크기가 달라서
